# Sparse Table（ST 表）

Sparse Table，常简称 **ST 表**，是一种专门处理「静态区间查询」的数据结构。

它最经典的用途是：给定一个数组 `a[1..n]`，多次询问区间 `[l, r]` 的最小值、最大值、最大公约数等。

## 特点

- 预处理：`O(n log n)`
- 查询：通常 `O(1)`
- 修改：不支持。如果数组会频繁修改，用线段树或树状数组。

## 核心思想

ST 表预处理所有长度为 `2^k` 的区间答案。

定义：

```text
st[k][i]
```

表示从位置 `i` 开始，长度为 `2^k` 的区间答案，也就是：

```text
st[k][i] = 区间 [i, i + 2^k - 1] 的答案
```

例如做区间最小值：

```text
st[0][i] = a[i];                 // 长度 1
st[1][i] = min(a[i], a[i + 1]);  // 长度 2
st[2][i] = [i, i + 3] 的最小值;  // 长度 4
st[3][i] = [i, i + 7] 的最小值;  // 长度 8
```

## 状态转移

长度为 `2^k` 的区间，可以拆成两个长度为 `2^(k-1)` 的区间：

```text
[i, i + 2^k - 1]
```

拆成：

```text
[i, i + 2^(k-1) - 1]
[i + 2^(k-1), i + 2^k - 1]
```

所以：

```cpp
st[k][i] = min(
    st[k - 1][i],
    st[k - 1][i + (1 << (k - 1))]
);
```

如果是最大值，把 `min` 换成 `max`。如果是最大公约数，换成 `gcd`。

## 查询为什么是 O(1)

假设要查询 `[l, r]` 的最小值。

令：

```cpp
int len = r - l + 1;
int k = log2(len);
```

也就是找到不超过区间长度的最大 `2^k`。

然后取两个长度为 `2^k` 的区间：

```text
[l, l + 2^k - 1]
[r - 2^k + 1, r]
```

这两个区间一定能覆盖 `[l, r]`。

所以答案是：

```cpp
min(st[k][l], st[k][r - (1 << k) + 1])
```

即使两个区间重叠也没关系，因为 `min`、`max`、`gcd` 这类操作重复计算不会改变结果。

例如：

```text
min(1, 1) = 1
max(5, 5) = 5
gcd(6, 6) = 6
```

但区间和不行，因为重复会改变答案。

## 手动例子

数组：

| 下标 | 1 | 2 | 3 | 4 | 5 | 6 |
| --- | --- | --- | --- | --- | --- | --- |
| 数值 | 4 | 2 | 7 | 1 | 5 | 3 |

做区间最小值。

### `st[0]`，长度为 1

```text
4  2  7  1  5  3
```

### `st[1]`，长度为 2

```text
st[1][1] = min(4, 2) = 2
st[1][2] = min(2, 7) = 2
st[1][3] = min(7, 1) = 1
st[1][4] = min(1, 5) = 1
st[1][5] = min(5, 3) = 3
```

### `st[2]`，长度为 4

```text
st[2][1] = min([1,2], [3,4]) = min(2, 1) = 1
st[2][2] = min([2,3], [4,5]) = min(2, 1) = 1
st[2][3] = min([3,4], [5,6]) = min(1, 3) = 1
```

### 查询 `[2, 6]`

区间长度：

```text
len = 5
```

最大 `2^k <= 5`，所以：

```text
k = 2
2^2 = 4
```

取两个长度为 `4` 的区间：

```text
[2, 5]
[3, 6]
```

答案：

```text
min(st[2][2], st[2][3]) = min(1, 1) = 1
```
